# Swift Subprocess

A one-file, dependency-free runner for external tools: launch, drain both pipes concurrently, return status + stdout + stderr.

- Module `Subprocess` in `Sources/Subprocess`; tests in `Tests`; `swift test` is the whole check.
- Swift 6 language mode, tools 6.0, macOS 14+, no dependencies unless the README says so.
- Part of the Sidewatch package family; every package follows the same layout and PR rules.
